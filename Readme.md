# GCP Security 

Explicación: Implementación de una postura de seguridad robusta en la nube. Se cubren los mecanismos de cifrado, gestión de identidades avanzada, secretos y auditoría para asegurar que el dato esté protegido en reposo y en tránsito. 

● Índice: 
- Seguridad avanzada: IAM avanzado; KMS (Gestión de claves); Secret Manager. 
-  Trazabilidad: Auditing y Logging; DLP (Data Loss Prevention). 
-  Principio de seguridad: Mínimo privilegio y cumplimiento normativo.
